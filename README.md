# Remna Admin — релизы

Android-приложение для администрирования панели **Remnawave** через REST API (Bearer API-токен).
В этом репозитории только готовые APK, исходного кода здесь нет.

## Возможности
- Дашборд: статистика системы
- Пользователи: поиск, создание, редактирование, продление, лимит трафика, сброс трафика, включение/отключение, сквады, удаление, ссылка подписки и QR-код
- Ноды: статус, перезапуск, включение/отключение, трафик, инбаунды и профиль
- Конфиг-профили: редактор JSON с проверкой и резервной копией перед сохранением (экспорт)
- Внутренние сквады: состав инбаундов
- Хосты: редактирование, порядок, скрытие/показ
- Шаблоны и настройки подписки

Все опасные действия требуют подтверждения. Токен хранится в EncryptedSharedPreferences и никогда не пишется в логи.

## Установка
Скачайте APK на странице [Releases](../../releases):
- `RemnaAdmin-*-universal.apk` — для любых устройств
- `RemnaAdmin-*-arm64-v8a.apk` — для современных ARM64-телефонов

Проверьте контрольные суммы по `SHA256SUMS.txt`. Требуется Android 8.0+.
